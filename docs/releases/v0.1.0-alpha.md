# v0.1.0-alpha release notes (draft)

Status: prepared, not tagged or published.

`v0.1.0-alpha` is the first proposed source-code release of rappidAI Quantum.
It packages the repository's reproducible compact-language-model development
workflows and their maintenance infrastructure. The release remains
experimental and requires the approval gates in
[release-checklist.md](release-checklist.md).

## Verified scope

- dataset preparation, filtering, deterministic splitting, tokenization, and
  manifest helpers;
- tokenizer training and validation workflows;
- model configuration and parameter-count validation;
- CPU-safe smoke-data and smoke-test paths;
- checkpoint save/resume logic for trusted local checkpoints;
- evaluation and diagnostic infrastructure;
- GGUF export command construction using an explicitly supplied external
  `llama.cpp` checkout;
- repository configuration, CPU CI, tests, documentation, and health checks.

Only behavior covered by the release verification record and passing CI should
be described as verified. Historical result reports remain experiment-specific.

## Important boundaries

- This is an alpha source release, not a production model release.
- Echelon production-data preparation and model training are incomplete.
- No benchmark leadership, broad adoption, safety certification, or performance
  guarantee is claimed.
- Pilot model and tokenizer artifact reuse terms remain separate from the source
  license and must be explicitly published before any open-weight claim.
- Dataset access remains subject to source terms and content rights.
- Resume state may contain Python pickle data and must be trusted.
- `llama.cpp` is not vendored; the tested reference revision is
  `d4cff114c0084f1fbc9b4c62717eca8fb2ae494a`.

## Compatibility

- Python: 3.11 and 3.12.
- CI: CPU-only; no GPU or network-dependent test is part of the default test
  selection.
- Supported developer hosts: Windows, Linux, and macOS, subject to the optional
  ML stack's platform support.

## Artifacts not included

The source release does not include model weights, tokenizer builds, datasets,
checkpoints, GGUF files, or generated training outputs. Public model artifacts
remain in their separate Hugging Face repositories with separate terms.

## Known gaps

- immutable historical dataset revisions are incomplete in some pilot configs;
- final `quantum-1.6-pilot` manifest and raw evaluations are not published here;
- reproducible CPU inference timing is not yet recorded;
- Echelon production-data and training runs are not complete;
- the public repository retains its historical `lumen-quantum` name.

## Upgrade note

There is no earlier packaged release to upgrade from. Existing users should
create a clean Python 3.11 or 3.12 environment, install the intended optional
dependency group, and review the new licensing and security boundaries before
running historical workflows.
