# Quantum 1 Echelon 1B evidence directory

This directory is reserved for small, reviewable evidence generated by the 1B
pipeline: architecture preflights, tokenizer A/B reports, calibration summaries,
decontamination summaries and run/evaluation metadata.

Large datasets, tokenizer binaries, checkpoints, logs and model exports must not
be committed here.

No file in this directory should be interpreted as proof of a completed stage
unless its own status and supporting manifest explicitly say so.
