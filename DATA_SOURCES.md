## FineWeb2-HQ

| Field | Recorded value |
|---|---|
| Repository | `epfml/FineWeb2-HQ` |
| Primary configuration | `deu_Latn` |
| Dataset license stated by publisher | ODC-By 1.0 |
| Additional terms stated by publisher | Common Crawl Terms of Use |
| Pinned Echelon revision | `c0c06e94fd3a44ae9e802b2b0fc533817601eb5e` |
| Pilot configuration status | Several older pilot configs still use mutable `main` and are not release-reproducible |

The dataset is derived from web crawl data. Its publisher warns that personal
information may remain and recommends additional filtering for sensitive or
harmful content. Source-page copyright and removal obligations can remain even
when the dataset collection has an open-data license.

No raw or tokenized dataset is tracked here. A release manifest must record the
exact dataset revision, configuration, filters, seeds, document counts, token
counts, removal process, and output checksums.

## Local smoke data

Contributor-supplied smoke inputs under ignored `data/raw/` are not covered by
the repository license automatically. Contributors must use data they can
lawfully process and must not commit private or restricted content.
