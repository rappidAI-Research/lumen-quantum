# Support

Use GitHub issues for reproducible bugs and documentation defects. Use
discussions only if enabled. Search existing reports first and include the
exact commit, Python version, operating system, CPU/GPU status, configuration,
minimal command, and redacted logs.

This is a sole-maintainer experimental project. Contributions are welcome, but
no response time, fix, compatibility window, or individual support is promised.
Security reports must follow `SECURITY.md`.
